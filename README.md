# Excel Inventory Management Tracker

## Project Overview
An Excel-based inventory management system designed to track stock movements, goods received, goods issued, and inventory levels.

## Features
- Inventory Master
- Goods Receipt Note (GRN) Records
- Goods Issued Tracking
- Automatic Closing Stock Calculation
- Reorder Level Monitoring
- Conditional Formatting for Reorder Alerts
- Interactive Inventory Dashboard
- Stock Comparison Charts

## Tools Used
- Microsoft Excel
- Excel Formulas
- Conditional Formatting
- Charts and Data Visualization

## Key Learning
- Inventory Management
- GRN Documentation
- Stock Reconciliation
- Inventory Tracking
- Supply Chain Operations
